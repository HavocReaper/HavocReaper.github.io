Sign in with a GitHub token to edit your site content. No code editing required.

How to get a token (1 minute)
  1. Go to GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Click Generate new token. Name it something like Portfolio CMS.
  3. Set expiry (e.g. 90 days). Under Repository access, choose Only select repositories and pick your portfolio repo.
  4. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else alone.
  5. Copy the token and paste it above. It starts with github_pat_.
Your token stays in this browser tab only. It is held in session storage, never written to your site or sent anywhere except GitHub. Closing the tab signs you out. Never share it or paste it into your website content.
